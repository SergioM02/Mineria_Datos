# Minería de Datos - Predicción de Clima en Australia

Este repositorio contiene el desarrollo de las evaluaciones de la asignatura Minería de Datos.

## 1. Conjunto de Datos (Dataset)
* **Nombre:** Rain in Australia
* **Fuente:** [Kaggle - Rain in Australia](https://www.kaggle.com/datasets/jsph92/weather-aus)
* **Descripción:** 10 años de observaciones meteorológicas diarias de varias ubicaciones en Australia.

## 2. Metodología
Se utilizará la metodología **CRISP-DM**, comenzando por la etapa de Entendimiento de los Datos y Preparación de los Datos.
